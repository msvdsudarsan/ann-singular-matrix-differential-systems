## Results Directory

This directory contains numerical outputs generated by the MATLAB-based
Physics-Informed Neural Network (PINN) experiments reported in the
manuscript:

**"Adaptive Physics-Informed Neural Networks for Singular Matrix Differential
Systems with Algebraic Structure Preservation: Applications to Optimal
Control Synthesis"**
Sri Venkata Durga Sudarsan Madhyannapu, Pradheep Kumar S.
*Engineering Applications of Artificial Intelligence* (Elsevier, 2026)
SSRN: [doi:10.2139/ssrn.6277631](https://doi.org/10.2139/ssrn.6277631)

---

### Contents

The directory includes:
- Saved solution trajectories (P11, P12, P22 for Riccati; y(t) for BVP and DDE)
- Error metrics (mean absolute error, maximum error, symmetry error)
- Training loss histories (all three problems, 4000 epochs)
- Adaptive collocation refinement data (boundary layer concentration)
- Robustness trial outputs (40 trials across σ ∈ {0, 0.01, 0.05, 0.10})

All numerical values reported in the manuscript were obtained by executing
the MATLAB scripts in the `matlab/` directory on MATLAB R2023b,
Intel Core i7, 16 GB RAM (no GPU).

### Reproducibility

To reproduce all reported numerical results, run the following in
MATLAB R2023b from the `matlab/` directory:

```matlab
run_all_experiments        % Tables 2–4 (Problems 1, 2, 3)
ablation_study             % Table 5
run_robustness_30trials    % Table 6 (40 trials: 10 per noise level)
gen_ALL_FIGURES_EAAI       % All 5 figures (PDFs)
```

Expected total runtime: ~60–90 minutes on Intel Core i7, 16 GB RAM.
All results verified on 12 May 2026, 16:15 IST.
