Results Directory

This directory contains numerical outputs generated by the MATLAB-based Physics-Informed Neural Network (PINN) experiments reported in the associated manuscript.

Contents

This directory may include:

Saved solution trajectories

Error metrics (mean absolute error, maximum error)

Training loss histories

Intermediate convergence data and adaptive refinement outputs

All numerical values reported in the accompanying manuscript were obtained by executing the MATLAB scripts provided in the matlab/ directory of this repository.

Reproducibility

To reproduce all reported numerical results, run the following command in MATLAB or MATLAB Online:
run_all_experiments
